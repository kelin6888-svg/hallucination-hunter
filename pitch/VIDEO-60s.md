# 60 秒游戏宣传片 · 分镜方案

**片名**：失控的周六 · 幻觉猎人
**一句话卖点**：AI 给你答案，后果由你承担。
**素材原则**：全部使用真实运行画面（`shots/materials/`），不摆拍、不合成假 UI。
**规格**：1920×1080 / 24fps / 60 秒 / 无对白，靠字幕 + 界面本身讲故事（现场可配旁白）。

## 分镜表

### Shot 01｜0:00–0:05　黑场字卡
- 画面：纯黑，中央两行字淡入
- 字幕：`AI 给你答案` / `后果由你承担`
- 处理：字重 Bold，字距略宽，出现后停留 1.2 秒再切
- 声音：低频铺底进入

### Shot 02｜0:05–0:12　首页（手机壳）
- 画面：`phone-home.png` 缓慢推近（1.00→1.06），暗角
- 字幕：`《失控的周六》` / `五个生活任务，一部手机里的助手`
- 处理：轻微上浮，模拟手持

### Shot 03｜0:12–0:18　抢票场景
- 画面：`loss.png` 全屏，镜头对准手机中部的订单卡与客服消息
- 字幕：`客服："站内支付拥堵，点这个链接"` / `助手："可能是官方备用通道"`
- 处理：字幕出现的瞬间画面压暗 8%，把注意力交给那句建议

### Shot 04｜0:18–0:22　点击
- 画面：同一张图，快速推近到付款按钮
- 字幕：`他点了`
- 处理：0.3 秒白闪（5% 亮度）表示按下；此处是全片第一个节奏点

### Shot 05｜0:22–0:27　资源条特写
- 画面：`loss.png` 顶部资源条放大 2.2 倍，红框标 `¥320`
- 字幕：`¥500 → ¥320` / `票也没了，任务停在 0/5`
- 处理：数字用红色，配合一次轻微震动（位移 2px，两帧）

### Shot 06｜0:27–0:30　字卡转折
- 画面：黑底一行白字
- 字幕：`但核实只需要 6 分钟。`

### Shot 07｜0:30–0:35　核实
- 画面：`verify.png`，镜头从订单卡缓慢横移到「账号注册 3 天 · 无认证」
- 字幕：`查订单、查账号` / `同一个链接，不属于官方渠道`
- 处理：横移速度恒定，不加速

### Shot 08｜0:35–0:40　算错钱
- 画面：`budget.png`，购物车与「现付 66 / 预算 60」
- 字幕：`"一共 96，最后 56，预算内"` / `结算页：66 元，超了`
- 处理：`66` 出现时加一次 1.05 倍脉冲

### Shot 09｜0:40–0:45　推断错
- 画面：`parcel.png`，物流地图 + 完整轨迹
- 字幕：`"包裹应该已经到小区门口了"` / `实际还在配送站`
- 处理：地图三个节点依次亮起（0.2 秒间隔）

### Shot 10｜0:45–0:50　结尾结算
- 画面：`final.png`，从分数环拉开到整页
- 字幕：`500 分 · 四种结局` / `每一次判断都被记下来`

### Shot 11｜0:50–0:54　链上
- 画面：`final.png` 右侧「Monad 测试网 成绩记录」区块放大
- 字幕：`全程两次签名` / `开局一次，交成绩一次`
- 处理：不出现任何交易哈希（尚未部署时不能伪造）

### Shot 12｜0:54–1:00　落款
- 画面：黑底，紫色细线 + 标题
- 字幕：`幻觉猎人` / `Don't Trust. Verify.` / `Monad 测试网 · 黑客松`
- 处理：字标淡入后保持，最后 0.4 秒整体淡出

## 制作规范

- **安全区**：左右各 80px，底部字幕基线不低于 120px，避免被平台 UI 压住。
- **字幕**：主行 40–46px Bold，副行 24px Regular，#F4F5FA / #A8ADC4；关键词用 `#FF7171`（损失）或 `#34D399`（验证）。
- **转场**：统一 0.35 秒交叉溶解；只有 Shot 04 用硬切，制造"按下去"的实感。
- **音乐**：低频 pad + 每 8 秒一次的轻微脉冲；不要用带旋律的商业曲，避免版权风险。现场可用无音乐版。
- **禁止**：假交易哈希、假用户评价、假媒体报道、把模拟支付说成真实支付。

## 三分钟路演里的用法

- 0:00–0:40 放 Shot 01–05（到资源条特写），停在 `¥320` 上开口："这不是 bug，是 AI 的建议。"
- 讲完玩法后放 Shot 07–10，用同一关的 100 分做对照。
- 最后 20 秒放 Shot 11–12，接现场演示链上工作台。
